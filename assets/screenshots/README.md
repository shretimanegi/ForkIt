# Project Screenshots

Store the important screenshots of the project in this folder.

## Recommended screenshots

- Landing screen / dashboard at rest
- File upload and job in progress
- Processed waterfall image
- Detection table with results
- Map view with georeferenced detections
- Exported report (JSON / CSV / GeoJSON)

- `06-sensor-detection-csv.png` — CSV report export

## Naming convention

Use clear, ordered names — `01-`, `02-`, and so on, with a short description.

Do not upload screenshots containing passwords, API keys, tokens, personal
credentials or other sensitive information.

## Adding screenshots to README

Display important screenshots in the main `README.md` using a relative path:

```md
![Detection Dashboard](assets/screenshots/01-dashboard.png)
```
